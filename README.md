# Missing Value Identification

## Project Overview
This project identifies missing values in the Titanic dataset using Microsoft Excel. It summarizes missing data in selected columns and presents the results in a table and chart.

## Objectives
- Identify missing values in the dataset.
- Count missing values in each selected column.
- Calculate the percentage of missing values.
- Present findings using a summary table and chart.

## Tools Used
- Microsoft Excel
- Titanic dataset (CSV)

## Results

| Column | Missing Values | Missing Percentage |
|---|---:|---:|
| Age | 177 | 19.87% |
| Cabin | 687 | 77.10% |
| Embarked | 2 | 0.22% |

## Key Findings
- The Cabin column contains the highest number of missing values.
- The Age column also contains missing data.
- Only two values are missing from the Embarked column.
- Missing values should be handled carefully to avoid losing useful information.

## Conclusion
This project demonstrates how Excel can be used to identify and summarize missing data. The results help us understand data quality before performing further analysis.
